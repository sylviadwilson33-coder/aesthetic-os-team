事实：照片路径、作者和原帖地址来自仓库 `gallery-data.js`。逐张看过本地原图后选入，不新增网络抓图。

授权依据：仓库 README 与现有图库说明称这些博主图片已由站长私信取得展示授权。本次沿用这一项目记录，没有拿到私信原件，也不声称独立核验授权范围。若原授权只限穿搭图库、未涵盖其他图鉴，应由负责人确认后再上线这些复用记录。

原作者观点：本批未取得原帖正文，不将图鉴说明、风格分组和用时写成博主观点或教程。原帖地址沿用仓库记录，本次未逐条在线验证其可访问性，可能要求登录。

本项目解读：发型按照片可见形态整理，发色受滤镜与光线影响。妆容只借用照片中的眼、眉、唇细节，练习时间是项目估计；前卫型的几何延伸属于练习建议，原图不是完整几何妆示例。身材只借用服装版型，不依据照片断定任何博主的胸腰臀或身材类型。人物均沿用既有成人博主图库记录，没有新增陌生人物素材。
